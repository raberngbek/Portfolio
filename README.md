# CHHAENG SOKUNTHEARA — Portfolio

Personal UI/UX and Product Design portfolio built with React and Tailwind CSS.

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router

## Features

- Responsive portfolio
- Product design case studies
- Resume download
- Project showcase
- Contact links

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
